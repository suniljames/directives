# Command starters

The five pipeline slash commands, ready to copy into your project. What they are and how to install them: [`docs/commands.md`](../../docs/commands.md).

| File | Command |
|---|---|
| [`define.md`](define.md) | `/define` — requirements review (PRD) |
| [`design.md`](design.md) | `/design` — committee design review |
| [`implement.md`](implement.md) | `/implement` — test-first build |
| [`review.md`](review.md) | `/review` — code review & merge |
| [`summarize.md`](summarize.md) | `/summarize` — stakeholder summary |

Each file is generic by design; project specifics (your quality-gate command, your domain rules) go in your copy, not here.
